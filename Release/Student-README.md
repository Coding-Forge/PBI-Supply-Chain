# Power BI Workshop: Student Quick Start

This package contains the student materials for a four-part Power BI workshop.

## Start here

1. Extract the entire ZIP file to a local folder. Do not open the HTML files from inside the ZIP.
2. Open `Lab\index.html` in Microsoft Edge or another current browser.
3. Keep the course page open beside Power BI Desktop.
4. Complete Labs 1–4 in order.

Your browser stores checklist progress locally on the device. Progress does not synchronize to another computer or browser profile.

## What you need

- Current Power BI Desktop
- Access to `raw.githubusercontent.com`
- For Lab 4, a government Power BI Pro or Premium Per User license and access to an approved workspace
- Permission to use the appropriate GCC, GCC High, or DoD Power BI service endpoint

## Package contents

| Folder | Purpose |
| --- | --- |
| `Lab` | Course home, four guided labs, optional follow-up page, and branding assets. |
| `Images` | Screenshots displayed by the lab pages. |
| `Data` | Local CSV copies for use when the public GitHub source is unavailable and your instructor approves local-file use. |

Completed reports are intentionally excluded. You will build the report during the workshop.

## Data and security

The Coding-Forge data is fictitious. Do not substitute controlled, classified, export-controlled, customer, or operational data during the workshop.

If the GitHub Web source is blocked, use the matching file in `Data` with **Get data → Text/CSV** only after checking with your instructor. Do not bypass network or tenant policy.

## Lab path

1. Connect to GitHub data.
2. Transform the data and build the model.
3. Build and validate the report.
4. Publish and test it in the appropriate Power BI US Government environment.

The Follow Up page contains optional production-readiness enhancements and is not required to complete Lab 4.
