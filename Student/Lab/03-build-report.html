Lab 3 · Analysis and communication

Build a report that supports decisions

Create reusable DAX measures, then organize visuals around three questions: Where are we over budget? Where is procurement exposure concentrated? What should leadership review first?

35–45 minutesReport view + DAXDeliverable: 3 report pages

Create a measures table

  1. Select Home → Enter data.
  2. Name the table _Measures, name its single column Measures, enter one value of 1, and select Load.
  3. Hide the Measures column in Report view after you have created the measures.
  4. For each formula below, select New measure and set its Home table to _Measures.
Why measures? Measures calculate in the current filter context. The same formula works correctly in a card, chart, matrix, drillthrough page, or tooltip.

Core measures

Total Budget = SUM('Budget vs Actuals'[Budgeted Amount])
Total Actual = SUM('Budget vs Actuals'[Actual Amount])
Budget Variance = [Total Budget] - [Total Actual]
Budget Variance % = DIVIDE([Budget Variance], [Total Budget])
Total PO Value = SUM('Purchase Orders'[PO Amount])
Outstanding PO = SUM('Purchase Orders'[Amount Remaining])
PO Count = DISTINCTCOUNT('Purchase Orders'[PO ID])

Format money measures as Currency with 0 decimal places. Format Budget Variance % as Percentage with 1 decimal place.

Match the completed-report presentation

  1. Set each page to a custom 1920 × 1080 canvas (16:9).
  2. Add a clear page heading: Financial Health, Procurement Exposure, or Executive Review.
  3. Use a light neutral canvas, white visual surfaces, subtle gray borders, and a restrained navy/teal finance palette.
  4. Use explicit chart and table titles that state the decision being supported.
  5. Keep 24–32 px gaps between visuals and align edges across each row.
  6. On Executive Review, add two Page navigation buttons targeting Financial Health and Procurement Exposure. Keep both controls in the top-right header band.
Completed-report design choice: Financial Health uses four individual KPI cards. Procurement Exposure and Executive Review each use one grouped card visual containing three measures, which keeps related KPIs aligned and reduces container clutter.

Apply conditional background formatting

On the Procurement Exposure table, use color to make Priority easier to scan while keeping the text visible.

  1. Select the table visual.
  2. In the Build pane, open the menu beside Priority.
  3. Select Conditional formatting → Background color.
  4. Set Format style to Rules, Apply to to Values only, and base the rules on Priority summarized by First.
  5. Add text rules for Critical (red), High (yellow), Medium (peach), and Low (green).
  6. Select OK, then confirm every row still shows its Priority text over the background color.
Do not rely on color alone: retain the Priority text and use colors with enough contrast. Apply numeric data bars or a color scale separately to Amount Remaining if useful.

Configure interactions

  1. Select a chart, then Format → Edit interactions.
  2. Let Program and Branch selections filter all relevant visuals.
  3. Use highlight only when the retained total provides useful context.
  4. Keep cards filtered; leadership should see that a slicer changed the scope.
  5. Test one program selection on every page, then clear all filters.

Accessibility and finish

  • Use descriptive titles such as “Outstanding PO value by vendor,” not “Bar chart.”
  • Add alt text under Format → General → Properties for each meaningful visual.
  • Do not communicate status through color alone; retain labels and values.
  • Use consistent currency display units and decimal precision.
  • Align visuals and keep page navigation in the same location.
